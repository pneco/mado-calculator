장비 변경 시뮬레이션

현재 마도 저항은 게임에 표시된 전체 값입니다. 장비 변경 전후의 차이만 전체 저항에 반영해 이중 계산을 방지합니다. 장비 변화에 따른 전투력 증감은 반영하지 않습니다.

저장 / 백업

변경 사항은 자동 저장됩니다. 다른 기기로 옮기거나 Safari 데이터 삭제에 대비하려면 JSON 파일로 백업하세요.

잔영·해연 수치는 커뮤니티 기준 참고 모델입니다. 잔영 1~11단계: 140부터 단계당 +28, 해연 1~21단계: 420부터 단계당 +14, 무기 2배로 가정합니다. 게임 공식 확정 수치가 아니므로 실제 장비 표시값과 대조해 주세요. 마도 피해 변화는 검증되지 않은 참고 근사식입니다. 마도 압력보다 저항이 낮으면 음수(피해 감소 추정)로 표시하며, 실제 게임의 피해 감소율과 일치한다는 보장은 없습니다.
